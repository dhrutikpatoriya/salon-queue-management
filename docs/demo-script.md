# Three-minute mobile demonstration

Use a 390 px phone viewport or screen recording from a phone. Record during salon hours. Prepare tabs for Customer, Reception, Barber, TV, and Owner. Sign in to staff screens before recording, keep password entry off-screen, use only dummy customer details, and leave one eligible ticket waiting for the barber to call. Start the recording after verifying the public demo URL.

| Time | Show | Say or caption |
|---|---|---|
| 0:00–0:15 | Open the verified public link on a phone. | “This is a same-day queue for a single salon. Customers can see availability before joining.” |
| 0:15–0:45 | Choose services and a barber preference. Join, then show My Status and the token. | “The queue keeps my barber preference and shows an updated place and waiting estimate.” |
| 0:45–1:15 | Switch to Reception, add a walk-in, then Call Next for the eligible barber. | “Reception adds walk-ins to the same queue. Call Next picks the oldest eligible customer.” |
| 1:15–1:50 | Show Barber Portal, select the signed-in barber tab, tap Start, then Complete. Show My Status changing. | “Only the assigned barber can start or complete this service. The status updates live.” |
| 1:50–2:15 | Show the TV current token and next five. Switch to Gujarati and show Exit Display. | “The TV displays token labels and barber states without customer contact details.” |
| 2:15–2:50 | In Owner Settings, pause online joining and show Home’s closed join button. Show Staff Access without opening a credential form. Restore the previous setting. | “The owner can change hours, services, duty and access. During physical opening hours, reception can still take walk-ins.” |
| 2:50–3:00 | Return to the homepage and show the verified URL and GitHub link. | “The repository includes the prompt log, security checks, and deployment instructions.” |

Trim idle time and mistakes to **3:00**. Confirm the recording contains no real customer data, credential entry, terminal secrets, or hosting dashboard details. Upload the clip to the assignment submission location and add the shareable link to README.
